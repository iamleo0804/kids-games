# 兒童大冒險 - 設計系統 (Design System)

本專案採用 **iPad 優先 (Touch-First)** 的設計策略，強調圓潤感、鮮豔色彩與動態回饋。

## 1. 色彩系統 (HSL Colors)

| 用途              | 變數名稱            | HSL 值               | 視覺感受         |
| :---------------- | :------------------ | :------------------- | :--------------- |
| **主色 (天藍)**   | `--color-primary`   | `hsl(198, 93%, 60%)` | 寬廣、科技、導覽 |
| **次色 (橘黃)**   | `--color-secondary` | `hsl(35, 100%, 60%)` | 能量、獎勵、注意 |
| **成功 (嫩綠)**   | `--color-success`   | `hsl(145, 63%, 49%)` | 正確、完成、生長 |
| **危險 (珊瑚紅)** | `--color-danger`    | `hsl(354, 85%, 63%)` | 錯誤、警告、挑戰 |
| **強調 (紫色)**   | `--color-accent`    | `hsl(280, 67%, 60%)` | 神秘、進階、大師 |

## 2. 圓角與陰影 (Radius & Shadows)

- **大型圓角 (`--radius-lg: 24px`)**：用於主要容器與大型按鈕 (XL)。
- **中型圓角 (`--radius-md: 16px`)**：用於標準按鈕與卡片。
- **立體陰影 (`--btn-shadow`)**：底部 6px 的深色投影，營造實體按鍵感。

## 3. 按鈕互動規範

- **正常狀態**：顯示底部邊框陰影。
- **點擊狀態 (`:active`)**：
  - 向下位移 `4px` (`translateY(4px)`)。
  - 陰影縮小。
  - 產生微微的縮放動畫。

## 4. 字體 (Typography)

- **字型**：優先使用 `Outfit` (Google Fonts)，這是一款圓潤且幾何感強的無襯線字體，非常適合兒童介面。
- **重磅等級 (800)**：用於標題與按鈕文字，確保清晰易讀。

## 5. 動畫原則

- **Bouncy (彈跳感)**：答對時圖示應有縮放彈跳。
- **SlideUp (滑入)**：頁面切換時由下而上淡入，符合 iPad OS 的視覺習慣。
